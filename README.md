# Customer Segmentation Using RFM Analysis

A customer segmentation project built around transactional sales data. It prepares the data for analysis, calculates Recency, Frequency, and Monetary (RFM) metrics, groups customers by purchasing behavior, and presents the results in a Power BI report.

## Project workflow

- Clean and prepare transactional customer data for analysis.
- Calculate RFM metrics:
  - **Recency:** how recently a customer purchased.
  - **Frequency:** how often a customer purchased.
  - **Monetary:** how much a customer spent.
- Segment customers into groups such as loyal customers, customers at risk of churning, and new customers.
- Analyze purchasing behavior across the segments.
- Use the segment insights to guide targeted marketing recommendations, such as loyalty offers, win-back campaigns, and new-customer onboarding.
- Explore the results through the included Power BI report and supporting visual assets.
